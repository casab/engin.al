The APC40 mkII is built for launching clips. This control surface script turns it into a Push-style instrument:

- a step sequencer with drum pads, and a melodic scale keyboard that follows Live's scale
- VU meters and a session overview on the pad grid
- fixed-length recording per track, takes and a count-in
- all of the stock session, mixer, device and transport control

Built from the end of September 2026: v1.0.0 on 7 October, v1.4.3 on 26 October. The illustrated user manual is generated from the script itself, so it never drifts from what the buttons do. It's available from [apc40x.com](https://apc40x.com), with every update free.
